## Лабораторная работа №5: Регулярные выражения в Java

## Описание

В данной лабораторной работе реализованы пять задач на использование регулярных выражений в Java. Каждое задание демонстрирует применение классов `Pattern` и `Matcher` для поиска, проверки и обработки текстовых данных. Программы поддерживают как латиницу, так и русский язык (с учётом буквы `ё`).

## Содержание

1. Поиск всех чисел в тексте
2. Проверка корректности пароля
3. Поиск заглавной буквы после строчной
4. Проверка корректности IP-адреса
5. Поиск слов, начинающихся с заданной буквы
   

## Задание 1: Поиск всех чисел в тексте

Программа находит все числа (целые и дробные, положительные и отрицательные) в заданном тексте и выводит их. Регулярное выражение `-?\d+(?:\.\d+)?` позволяет находить числа с необязательным знаком минуса, целую часть и необязательную дробную часть. Для поиска используется метод `matcher.find()` в цикле, а найденные значения сохраняются в список и выводятся через запятую. Программа корректно обрабатывает некорректные числа (например, `12.34.56` игнорируются).

Пример работы: для текста `"Цена: 19.99, скидка: -5, количество: 42"` программа найдет числа `19.99`, `-5` и `42`.


## Задание 2: Проверка корректности пароля

Программа проверяет, соответствует ли пароль заданным требованиям: длина от 8 до 16 символов, только латинские буквы и цифры, хотя бы одна заглавная буква и хотя бы одна цифра. Используется регулярное выражение `^(?=.*[A-Z])(?=.*\d)[A-Za-z\d]{8,16}$`, где `(?=.*[A-Z])` и `(?=.*\d)` — это позитивные проверки вперёд (lookahead), которые проверяют наличие заглавной буквы и цифры в любом месте строки, не захватывая их. Основная часть `[A-Za-z\d]{8,16}` проверяет допустимые символы и длину, а `^` и `$` обеспечивают проверку всей строки целиком.

**Пример работы:** пароль `"Pass1234"` будет признан корректным, а `"password"` — нет (отсутствуют заглавные буквы и цифры).


## Задание 3: Поиск заглавной буквы после строчной

Программа находит в тексте все места, где после строчной буквы сразу идёт заглавная, и выделяет их восклицательными знаками с двух сторон. Регулярное выражение `([a-zа-яё])([A-ZА-ЯЁ])` использует две захватывающие группы: первая для строчной буквы (поддерживаются латиница, русские буквы и `ё`), вторая для заглавной. В строке замены `!$1$2!` специальные символы `$1` и `$2` подставляют текст, захваченный группами, а восклицательные знаки добавляются по краям. Метод `matcher.replaceAll()` выполняет замену всех найденных совпадений.

Пример работы: текст `"приветКакДела"` преобразуется в `"приве!тК!а!дД!ела"`.


## Задание 4: Проверка корректности IP-адреса

Программа проверяет, является ли строка корректным IPv4-адресом. IP-адрес должен состоять из четырёх чисел, разделённых точками, каждое число должно быть в диапазоне от 0 до 255 без ведущих нулей. Регулярное выражение для одного октета: `(25[0-5]|2[0-4][0-9]|1[0-9][0-9]|[1-9][0-9]|[0-9])`, где последовательно перечислены возможные варианты: 250-255, 200-249, 100-199, 10-99, 0-9. Полное выражение собирается из четырёх октетов, разделённых экранированными точками `\\.`, и обрамляется `^` и `$` для проверки всей строки.

Пример работы: `"192.168.1.1"` — корректный адрес, `"01.1.1.1"` — некорректный (ведущий ноль), `"256.1.1.1"` — некорректный (число больше 255).


## Задание 5: Поиск слов, начинающихся с заданной буквы

Программа находит все слова в тексте, начинающиеся с заданной буквы. Регулярное выражение `\b[буква][а-яА-ЯёЁa-zA-Z]*\b` использует `\b` для обозначения границ слова (для русского языка требуется флаг `UNICODE_CHARACTER_CLASS`). После открывающей границы указывается заданная буква в символьном классе, затем любое количество букв русских и латинских, и закрывающая граница слова. Для поиска независимо от регистра используются флаги `CASE_INSENSITIVE` и `UNICODE_CASE`, а для поддержки русских букв в границах слова — флаг `UNICODE_CHARACTER_CLASS`. Поиск выполняется в цикле через `matcher.find()`.

Пример работы: для текста `"Мама мыла раму"` и буквы `'м'` программа найдёт слова `"Мама"`, `"мыла"`, `"Мама"`, `"мыла"`, `"мыл"`.


## Используемые технологии

- java.util.regex — пакет для работы с регулярными выражениями:
  - `Pattern` — компиляция регулярного выражения
  - `Matcher` — выполнение операций поиска и замены
  - `PatternSyntaxException` — обработка ошибок синтаксиса

## Основные флаги регулярных выражений

- `Pattern.CASE_INSENSITIVE` - Игнорирование регистра букв 
- `Pattern.UNICODE_CASE` - Поддержка Unicode при игнорировании регистра 
- `Pattern.UNICODE_CHARACTER_CLASS`-|- Поддержка Unicode для `\w`, `\b`, `\d`, `\s`
