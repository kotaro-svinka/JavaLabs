# Лабораторная работа №6: Коллекции в Java

## Содержание работы
1. **Задание 1 (TopWords):** Чтение текстового файла и вывод ТОП-10 самых частых слов с использованием `Map` и кастомной сортировки.
2. **Задание 2 (Stack):** Реализация собственной обобщенной структуры данных «Стек» на базе динамического массива.
3. **Задание 3 (SalesTracker):** Разработка объектно-ориентированной системы учета продаж в магазине с использованием `HashMap`.


## Описание заданий и логика реализации

### Задание 1: Поиск ТОП-10 популярных слов

Программа считывает текстовый файл по указанному пути, очищает слова от знаков препинания и приводит их к нижнему регистру для корректного подсчета.

*   **Коллекция:** `HashMap<String, Integer>`, где ключ — слово, значение — счетчик повторений.
*   **Сортировка:** Поскольку `Map` не поддерживает сортировку, пары «ключ-значение» переносятся в `ArrayList<Map.Entry<String, Integer>>`. Сортировка выполняется по убыванию значений с помощью анонимного класса `Comparator`.
*   **Безопасность:** Использование регулярного выражения `[^a-zа-я0-9]` предотвращает склеивание слов вокруг цифр и корректно удаляет пунктуацию.

### Задание 2: Обобщенный класс Stack<T>

Собственная реализация классического стека, работающего по принципу **LIFO** (Last In, First Out).

*   **Архитектура:** Класс принимает универсальный тип `<T>`. Внутреннее хранилище реализовано на базе массива `Object[]` с безопасным приведением к `T[]`.
*   **Методы:**
    *   `push(T element)` — добавление элемента на вершину стека.
    *   `pop()` — удаление и возврат верхнего элемента (с занулением ссылки для предотвращения утечек памяти).
    *   `peek()` — просмотр верхнего элемента без изменения структуры стека.

### Задание 3: Система учета продаж (Вариант 5)

ООП-программа для отслеживания торговых операций в магазине.

*   **Класс `Product`:** Описывает товар (имя, цена). В классе переопределены методы `equals()` и `hashCode()`. Это необходимо для того, чтобы `HashMap` определяла идентичность товаров по их внутренним свойствам, а не по адресу объектов в памяти.
*   **Класс `SalesTracker`:** Содержит `HashMap<Product, Integer>`. Позволяет аккумулировать количество проданных единиц товара, выводить структурированный чек, рассчитывать суммарную выручку и находить самый продаваемый товар методом линейного поиска максимума.
